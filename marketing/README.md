# Marketing / social helper files (private)

These files support **owner-led promotion only**. They are:

- **not** part of the Next.js app (`marketing/` is outside `src/` and `public/`),
- **not** built, served, routed or indexed,
- hooks that are curiosity-led but **factually faithful** — no sensational claims,
  no fabricated figures, no fake scarcity.

Each `social/<slug>.md` maps to a published page and ends with a CTA to that
page's calculator or guide. Verify every number against the live page/source
before posting.
